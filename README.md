The one-line cat joke that lands: asked for space, given the closest
possible contact instead.

`main.py` (pure Python standard library, `os` only) writes exactly one line
— 44 characters — the cat joke, to `/output/entry.txt`.

## Why this line

> I asked my cat for space. He sat on my face.

A literal misdirection on the word "space": asked for distance, given the
closest possible physical contact, on the face. The turn lands at the very
end, in 44 characters, with nothing explained after the punchline — and it
dodges every stock cat premise in the field: nothing knocked off a table,
no box, no rent, no keyboard, no 3 a.m. zoomies.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` overrides the
output directory). Deterministic: the same line, byte for byte, on every run.
